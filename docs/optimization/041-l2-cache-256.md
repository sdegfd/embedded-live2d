# 041 P4 L2 cache 256 KB

Status: kept in the P4 example. Shared raster source is unchanged from `846b65e`.

Textures for the formal model are 184235 pixels, about 737 KB, plus a 320×320 ARGB framebuffer of 400 KB. Neither fits in the previous 128 KB L2. Espressif's P4 manual gives L2 sizes of 128 / 256 / 512 KB out of 768 KB L2MEM. This step changes only the P4 example cache and the internal DMA reserve.

`CONFIG_CACHE_L2_CACHE_256KB` with the old `CONFIG_SPIRAM_MALLOC_RESERVE_INTERNAL=262144` does not boot. The DMA heap at `0x4FF40000` shrinks from 384 KB to 256 KB, and `esp_psram_extram_reserve_dma_pool` returns `ESP_ERR_NO_MEM` (`0x101`) before the benchmark starts. The reserve is therefore 131072 bytes in `sdkconfig` and `sdkconfig.defaults`. That is the smallest companion change that lets the 256 KB cache reach `app_main`.

A control with L2 left at 128 KB and the reserve already at 128 KB reproduces the [reorg-final](../benchmarks/reorg-final.md) raster and frame times. The reserve change is not the speedup. Raw rows: [phase4_l2_256](phase4_l2_256/summary.csv), [phase4_l2_128_reserve128](phase4_l2_128_reserve128/summary.csv).

Conditions match the baseline short capture: warmup 5, measure 50, scale 1.0, 360 MHz CPU, 200 MHz PSRAM, 320×320, fast-nearest, PPA FILL, PPA SRM ROI, synchronous RGB565. Model SHA256 `1d7f21471dcedee2d205904791df7147c63760269462ad5d7169a97afe386100`. Deadline misses are 0 in every column. No approximate raster path was added. This image is the timing build, so device CRC was not recaptured; the raster source is the baseline source.

MULTI_AXIS frame p95 / max is 28627 / 28809 µs at the baseline, 28584 / 28815 µs on the control, and 27350 / 27678 µs with 256 KB L2. MULTI_AXIS raster p95 / max moves from 19480 / 19510 µs to 18158 / 18182 µs. Producer average moves from 27627.90 µs to 26438.60 µs. PPA SRM average moves from 4397.54 µs to 4604.10 µs on the 256 KB image and stays at 4388.64 µs on the control, so the extra SRM time comes with the larger cache and is smaller than the raster saving.

512 KB L2 was not built. The same DMA heap would lose another 256 KB. The raster remains about 18.0 ms of a 26.7 ms MULTI_AXIS frame.
