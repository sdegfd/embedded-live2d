A host probe of one fast-nearest frame counted 52759 in-bounds samples, 5331 spans, 8671 entries into a new 64-byte texture line, and 7237 entries into a new 128-byte line. Only 597 samples changed texture row relative to the previous sample, and 2430 samples repeated the same texel. The horizontal step is the common case, so a wider L2 line can bring the next texels in the same PSRAM fill. The probe was removed before this measurement. L1 remains 64 bytes; only the L2 line size changed.

The first 128-byte-line image kept 64-byte framebuffer alignment. That image is not the result below. `sys_display_buffer` now aligns the ARGB and RGB565 buffers to 128 bytes, which also satisfies the previous 64-byte DMA alignment. PPA fill runs again.
